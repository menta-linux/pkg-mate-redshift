# mate-redshift Debian packaging

This repository creates source and binary Debian packages for
[mate-redshift](https://github.com/KeremSoke/mate-redshift), then attaches them
to archived GitHub Releases. See [CHANNELS.md](CHANNELS.md) for the channel and
version rules.

The package installs the MATE Night Light settings utility and its manual page.
At runtime it uses `redshift-gtk` to configure and control the Redshift service.
